# Ahmed Fadhl — Portfolio

Personal portfolio and CV website for Ahmed Fadhl — IT Professional & AI Specialist.

Built with React, TypeScript, Vite and Tailwind CSS. Bilingual (Arabic / English) with full RTL support.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production output is generated in the `dist/` directory.

## Environment

The contact form uses [Web3Forms](https://web3forms.com). Create a `.env.local` file with:

```
VITE_WEB3FORMS_KEY=your_access_key
```
